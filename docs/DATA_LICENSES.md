# Data Licenses / Provenance

## Synthetic content
The question vignettes and flashcards included in the prototype are explicitly labeled `SYNTHETIC_PROTOTYPE_CONTENT` and are not official Iranian residency examination questions.

## External source metadata
The repository stores source names, URLs, versions, and provenance notes for discovery and traceability. Copyrighted source books and official question booklets are not redistributed here by default.

## Telegram
Telegram channels are recorded as secondary discovery sources only. Their posts are not treated as authoritative without a linked primary source.

## Third-party code references
GitHub repositories discovered during research are reference inputs only. Their licenses must be checked before any code reuse. No third-party source code is copied into the project by this refactor.
