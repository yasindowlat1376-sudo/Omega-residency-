# Ω-PATH-STUDY — Four-year developmental curriculum
This is a competency-oriented scaffold, not an official IUMS rotation calendar. Exact national requirements, IUMS blocks, assessments, duty rules and case quotas remain UNKNOWN until verified from current official documents.

PGY1 foundations: normal histology; tissue processing and H&E quality; basic reaction patterns; specimen orientation and grossing; common biopsy patterns; low-to-high power microscopy; introductory IHC/special stains; lab safety/preanalytics; reporting language; case presentation and supervised feedback.

PGY2 core breadth: major organ-system pathology; cytopathology; hematopathology; clinical laboratory rotations; grading/staging principles; synoptic reporting; frozen-section fundamentals; structured differential and test stewardship.

PGY3 advanced integration: complex resections; subspecialty depth; molecular diagnostics; digital pathology; tumor boards; discrepancy review; QI; research methods; teaching.

PGY4 transition: diagnostic breadth; supervised service coordination; laboratory quality; consultative communication; critical-result pathways; board readiness; portfolio and readiness gaps.

Learning loop: CELL → MECHANISM → MORPHOLOGY → DIFFERENTIAL → ANCILLARY TESTS → REPORT / CLINICAL IMPACT → EXAM. Each topic includes normal structure, pathogenesis, gross/microscopic morphology, differential, test selection, limitations, reporting, clinical impact and retrieval practice.
