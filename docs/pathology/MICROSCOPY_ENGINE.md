# Ω-MICROSCOPY ENGINE
## Sequence
Adequacy and slide quality; low power architecture/pattern/distribution; intermediate power cell relationships/stroma/inflammation/necrosis/invasion; high power cytology/chromatin/nucleoli/mitoses/atypia; special features including margins/nodes/treatment effect; differential and discriminators; ancillary test question and limitations; integrated interpretation and supervisor review.

## Evidence discipline
FACT: directly observed feature or verified result. INFERENCE: interpretation supported by observations. HYPOTHESIS: plausible explanation requiring discrimination. UNKNOWN: absent or inadequate information. Preserve contradictions. A negative test does not automatically exclude disease; account for controls, technical validity, sampling and sensitivity.

## Output template
Adequacy; low-power architecture; intermediate-power pattern; high-power cytology; stroma/background; positive and relevant negative findings; differential (candidate → support → oppose → discriminator); ancillary tests (question → assay → controls → result → limitation); integrated interpretation; uncertainty/next step; supervisor feedback. Current UI captures core fields but does not read slides or produce autonomous diagnosis.
