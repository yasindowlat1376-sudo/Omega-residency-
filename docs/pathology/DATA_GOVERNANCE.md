# Ω-PATH-STUDY — Privacy and data governance
Public references retain publisher, edition/version, date, jurisdiction, URL and access state. De-identified learning abstractions are stored only when institutional policy permits and re-identification risk is acceptably low. Patient-identifiable data is prohibited from this workspace, GitHub, Library memory and external AI prompts. Institutional patient record remains in authorized LIS/EHR.

Never enter patient name, national ID, DOB, phone, address, accession/barcode, identifying encounter date, identifiable image, rare combination of details that could re-identify a patient, credentials or report screenshots with identifiers.

Pathology records are nested within Ω-RESIDENCY StudyState and its storage/export/import path. No parallel database. Local browser storage is not a hospital-approved record system; exported JSON is sensitive.

Use images/case data only when de-identified and institutionally authorized. A checkbox is not proof of de-identification. Never send identifiable material to an external model without lawful basis, institutional approval and approved data processing.

MVP has user-initiated case deletion and JSON export. Formal retention schedule, secure erase guarantees, access control, encryption-at-rest and institution-approved hosting are not implemented.
