# Ω-GROSSING ENGINE
A gross description is a factual, reproducible record. Never invent dimensions, weight, orientation, margins, lesion features, cassette counts or sampling.

## Structured sequence
Procedure and specimen parts; orientation and landmarks; overall dimensions and weight when applicable; external surface/serosa/capsule/mucosa; opening and cut surface; lesion site/number/size in three dimensions/shape/color/consistency/border/depth/landmarks; margins and inking map; adjacent structures/nodes/background; representative sampling and cassette map per current organ/disease protocol; fixation and special handling.

## Dictation
Concise, neutral, reproducible and anatomically ordered. State exact units and dimension order. Describe what is seen, not presumed. Separate gross impression from final microscopic diagnosis. If not assessed, say not assessed/unknown rather than normal.

## Planned sampling engine
Procedure-aware templates: core biopsy, polypectomy, mucosal biopsy, skin ellipse, lymph node, prostate cores/prostatectomy, colectomy, gastrectomy, liver biopsy, hysterectomy, gallbladder, breast. Conditional sampling depends on lesion site/size, margins, landmarks, nodes, treatment effect and protocol. Every block maps to reason and location. Protocol version/source/date required. Human confirms all blocks; no automatic cassette prescription. Current code is a generic structured text builder only.
