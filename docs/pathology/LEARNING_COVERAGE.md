# Ω-PATH-STUDY learning coverage map

## General Pathology foundations

| Unit | Core scope | Diagnostic practice |
|---|---|---|
| Cell injury and cell death | Adaptation, reversible/irreversible injury, necrosis, apoptosis | Separate morphology from mechanism and cause |
| Inflammation | Acute/chronic, granulomatous, suppurative patterns | Pattern first; etiology requires correlation |
| Repair and fibrosis | Regeneration, granulation tissue, scar, remodeling | Distinguish active injury from repair |
| Hemodynamics | Edema, congestion, thrombosis, embolism, infarction, shock | Apply Virchow triad and distinguish antemortem thrombus |
| Neoplasia | Clonality, invasion, grade, stage, metastasis | Do not equate atypia, grade and stage |
| Immunopathology | Antibody, immune-complex, T-cell and innate injury | Match morphology to a discriminating ancillary test |
| Infection | Host-response patterns and organism detection | Separate colonization, contamination and tissue invasion |
| Molecular pathology | Alterations, tumor fraction, assay limits, VUS | State assay scope and clinical question |

## Normal histology

Esophagus, stomach, small intestine, colon, liver, pancreas, kidney, prostate, lung, thyroid, skin, breast, endometrium, lymph node and bone marrow are included in the current atlas.

## Learning design

Each unit contains a concise concept summary, key cellular/mechanistic elements, recognition anchors, common interpretive pitfalls, a practical next-step prompt and reference labels. Active recall questions are linked to lesson IDs and checked by automated tests for referential integrity.

## Content limitations

This is a PGY1-oriented introductory layer, not a complete specialist textbook or validated examination bank. Educational summaries are original paraphrases. Faculty review, image-based teaching, updated WHO classifications, local SOPs and official IUMS curriculum mapping remain future work.
